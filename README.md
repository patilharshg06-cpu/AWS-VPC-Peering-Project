# Evidence folder

Place your own AWS Console and terminal screenshots in this folder.

Suggested screenshots:
1. VPCs and subnet CIDRs
2. Route tables and subnet associations
3. Active VPC Peering connection
4. Security group inbound rules
5. Successful SSH to bastion
6. App-A to App-B ping output
7. App-B to App-A ping output
8. Controlled ICMP failure and recovery
9. Cleanup evidence

Only add screenshots you personally captured. Hide account IDs, email addresses, public IPs if not needed, and any sensitive information. Never add `.pem` files, passwords, AWS access keys, or tokens.
